# Onus Homebrew tap

```sh
brew install onushq/tap/onus
```

Installs `onus` and `onus-plugin-svelte` from the [Onus releases](https://github.com/onushq/onus/releases) on macOS (Apple silicon and Intel) and Linux (x86-64 and ARM64).

`Formula/onus.rb` is generated by [`scripts/homebrew-formula.sh`](https://github.com/onushq/onus/blob/main/scripts/homebrew-formula.sh) and updated by the Onus release workflow; changes made here by hand are overwritten on the next release.
